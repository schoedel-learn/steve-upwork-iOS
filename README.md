# steve-upwork-iOS

Standalone intake form published with GitHub Pages.

The page submits to the existing Formspree endpoint and is marked `noindex, nofollow`.

## ARCHIVED 2026-10-17

The engagement this form served was a one-time experiment and has ended; the live
GitHub Pages site has been disabled and the repository archived (read-only). The
form's design is kept here as a reference — if it is ever reactivated, consider
posting through Schoedel Design's self-hosted form pipeline (`sd-form-relay` →
FreeScout tickets) instead of Formspree.
